新增手表端局域网同步：手机当服务端，同 Wi-Fi 下的手表端 LXXWear 直接取歌单、音频与歌词。

#### 新增

- 新增「LXXWear」手表端同步：侧栏进入，手机在本机起一个局域网服务，手表端 LXXWear 与手机连同一个 Wi-Fi 即可拉取歌单清单、音频与歌词，不经过任何服务器
- 可勾选要同步的歌单并逐个选歌；每个歌单能单独开「自动同步」，只把选歌之后新加进歌单的曲目带过去，不会重复传输已在手表上的歌
- 同步音质可选；配对方式为手机相机扫手表上的二维码（也支持从相册选图）
- 手机上调节歌词（偏移 / 倍速）后自动推送到手表端，手表上的歌词与手机保持一致
- 新增歌词手动匹配：长按歌词 →「匹配歌词」，按歌名 / 歌手搜索，从候选里选一条保存，本地记住不再走自动匹配
- 新增歌词调节模式：长按歌词 →「调节歌词」，可微调歌词时间偏移，并新增「歌词倍速」（默认 1.0，范围 0.5～2.0，精度 0.1）
- 调节模式支持确定 / 取消 / 重置；按系统返回键只退出调节模式，不会退出播放器
- 调节结果同时作用于 App 内歌词、桌面歌词与手表端歌词
- 小哔音乐（B 站音源）支持歌词：优先用 B 站播放器识别到的 BGM 名称匹配，没有时用视频标题清洗后匹配

#### 修复、优化

- 修复 B 站歌曲下载 403：CDN 按 UA 与 Referer 的组合判盗链，改用 BiliApp UA 加网页 Referer；封面下载同样补上 Referer
- 修复 B 站歌曲下载后标签写入失败：B 站音频实际是 fMP4，按文件头把扩展名从 .mp3 纠正为 .m4a，播放器与标签库都能正确识别
- 优化歌词拖动后的回跳：改为按锚点反解偏移量，不再受当前行起始时间影响，整行误差导致的跳回上一行问题已消除
- 优化歌词调节界面配色与搜索框样式，与顶部歌曲搜索框保持一致
- 优化检查更新：点「更新」改为用系统浏览器打开 APK 下载地址，避免受应用内下载与「安装未知应用」权限影响；打不开直链时退到 Release 页面
- 修复只勾歌单未选歌时，保存后勾选状态偶尔丢失的问题
